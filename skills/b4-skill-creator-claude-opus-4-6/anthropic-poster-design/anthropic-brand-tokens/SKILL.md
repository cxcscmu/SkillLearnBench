# Anthropic Brand Design Tokens

## Color Palette

Anthropic's visual identity uses warm, muted earth tones. The palette deliberately avoids
neon, saturated gradients, or "AI-tech" styling in favor of understated sophistication.

| Token Name              | HEX       | Usage                                         |
|-------------------------|-----------|-----------------------------------------------|
| Identity Light          | `#F0EDE8` | Page backgrounds, canvas fills                |
| Corporate Dark          | `#191919` | Primary text, dark UI elements, outer casings  |
| Primary Brand Accent    | `#D4A27F` | Key interaction points, CTAs, connector highlights |
| Secondary Brand Accent  | `#7C9082` | Supporting elements, thermal/environmental UI  |
| Tertiary Brand Accent   | `#6B8F8B` | Tertiary elements, PCB/circuit board substrates|
| Muted Mid Gray          | `#B0A99F` | Annotation lines, secondary text, dividers     |

## Typography

- **Heading font**: `Styrene A` — Anthropic's primary display typeface. Used for titles,
  product names, and heading blocks. When Styrene A is unavailable in the rendering
  environment, fall back to a clean geometric sans-serif (e.g., Helvetica Neue, Arial).
- **Body font**: `Söhne` or system sans-serif for body copy.

## Visual Style Rules

1. **Minimalism**: Generous whitespace, clean lines, no decorative noise.
2. **Low saturation**: All accent colors are muted. Never use pure saturated hues.
3. **No gradients**: Flat color fills only. Avoid glows, shadows with color, or neon effects.
4. **Annotation style**: Thin (1–1.5px) lines in Muted Mid Gray with small labels.
5. **Layout**: Left-aligned typography, structured grid, ample margins (≥5% of canvas).
