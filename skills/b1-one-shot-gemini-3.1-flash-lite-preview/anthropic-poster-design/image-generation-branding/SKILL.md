### Branding Principles
- **Minimalism:** Avoid gradients, shadows, or high-saturation colors unless explicitly requested.
- **Palette Control:** Utilize strict hex-based mapping for corporate components.
- **Visual Hierarchy:** Clearly separate technical layers using consistent line weights (Muted Mid Gray).
- **Typography:** Use sans-serif, low-weight headers for technical documentation.

### Implementation Checklist
1. Identify all required components (e.g., Casing, PCB, Battery).
2. Map components to requested color tokens.
3. Ensure background matches the Brand Identity Light.
4. Final Review: Compare against core brand tokens for saturation and style adherence.
