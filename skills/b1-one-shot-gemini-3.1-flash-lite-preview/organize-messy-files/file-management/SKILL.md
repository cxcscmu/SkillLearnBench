# File Management Skill

This skill provides the structure and command sequence for organizing files.

## Workflow
1. Create subject directories: `mkdir -p LLM trapped_ion_and_qc black_hole DNA music_history`
2. Move files using standard shell commands: `mv <file> <subject_folder>/`
3. Verify directory contents: `ls -R`
