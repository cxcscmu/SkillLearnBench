# Seven-Character Regulated Verse Tonal Patterns (七言律诗平仄格律)

## Core Principle: Pattern-First Composition

**The tonal pattern is a HARD CONSTRAINT, not a soft guideline.** You must SELECT a canonical pattern FIRST, then compose every line to FIT that pattern character-by-character. Never write freely and hope it fits.

## Modern Mandarin Tone Classification

- **平 (level tones):** 1st tone (阴平, e.g., 天) and 2nd tone (阳平, e.g., 人)
- **仄 (oblique tones):** 3rd tone (上声, e.g., 水) and 4th tone (去声, e.g., 大)

## The Four Canonical Forms

You MUST explicitly choose ONE of these four forms before composing.

### Form A: 平起平收首句入韵 (Level-start, level-end, first line rhymes)
```
Line 1: 平平仄仄仄平平 (rhyme)
Line 2: 仄仄平平仄仄平 (rhyme)
Line 3: 仄仄平平平仄仄
Line 4: 平平仄仄仄平平 (rhyme)
Line 5: 平平仄仄平平仄
Line 6: 仄仄平平仄仄平 (rhyme)
Line 7: 仄仄平平平仄仄
Line 8: 平平仄仄仄平平 (rhyme)
```

### Form B: 平起仄收首句不入韵 (Level-start, oblique-end, first line doesn't rhyme)
```
Line 1: 平平仄仄平平仄
Line 2: 仄仄平平仄仄平 (rhyme)
Line 3: 仄仄平平平仄仄
Line 4: 平平仄仄仄平平 (rhyme)
Line 5: 平平仄仄平平仄
Line 6: 仄仄平平仄仄平 (rhyme)
Line 7: 仄仄平平平仄仄
Line 8: 平平仄仄仄平平 (rhyme)
```

### Form C: 仄起平收首句入韵 (Oblique-start, level-end, first line rhymes)
```
Line 1: 仄仄平平仄仄平 (rhyme)
Line 2: 平平仄仄仄平平 (rhyme)
Line 3: 平平仄仄平平仄
Line 4: 仄仄平平仄仄平 (rhyme)
Line 5: 仄仄平平平仄仄
Line 6: 平平仄仄仄平平 (rhyme)
Line 7: 平平仄仄平平仄
Line 8: 仄仄平平仄仄平 (rhyme)
```

### Form D: 仄起仄收首句不入韵 (Oblique-start, oblique-end, first line doesn't rhyme)
```
Line 1: 仄仄平平平仄仄
Line 2: 平平仄仄仄平平 (rhyme)
Line 3: 平平仄仄平平仄
Line 4: 仄仄平平仄仄平 (rhyme)
Line 5: 仄仄平平平仄仄
Line 6: 平平仄仄仄平平 (rhyme)
Line 7: 平平仄仄平平仄
Line 8: 仄仄平平仄仄平 (rhyme)
```

## Step-by-Step Composition Workflow

### Step 1: Declare the chosen form
State explicitly: "I am using Form X: [name]" and write out the full 8-line template.

### Step 2: Lock the rhyme scheme first
- Identify which lines must rhyme (lines ending in 平).
- Choose a rhyme group (e.g., all rhyming lines end in the same modern Mandarin rhyme such as -ang, -ing, -an, etc.).
- Draft the final character of each rhyming line FIRST to ensure they share the same rhyme AND are 平 (1st or 2nd tone).

### Step 3: Draft each line to fit the template
- For each line, compose 7 characters that match the tonal template.
- Positions 2, 4, 6 are MANDATORY matches — these cannot deviate from the pattern.
- Positions 1, 3, 5 have some flexibility ("一三五不论") but should match the pattern when possible.
- Position 7 MUST match (it determines 平/仄 line ending).

### Step 4: Verify every line character-by-character
For EACH of the 8 lines, do this:
1. Write the character.
2. Write its pinyin with tone number.
3. Classify as 平 (tone 1 or 2) or 仄 (tone 3 or 4).
4. Compare against the template position.
5. Flag any mismatch at positions 2, 4, 6, 7 as ERRORS that must be fixed.

### Step 5: Fix violations
If any position 2, 4, 6, or 7 has a mismatch, replace that character with a synonym or restructure the phrase. Then re-verify.

### Step 6: Final verification checklist
Before outputting the final poem, confirm ALL of the following:
- [ ] Each line has exactly 7 characters
- [ ] Positions 2, 4, 6, 7 of every line match the chosen canonical template
- [ ] All rhyming lines end with the same modern Mandarin rhyme
- [ ] All rhyming line endings are 平 (1st or 2nd tone)
- [ ] Non-rhyming lines end in 仄 (3rd or 4th tone)
- [ ] The middle two couplets (lines 3-4, lines 5-6) exhibit antithetical parallelism (对仗)

## Common "一三五不论" Caveat

While positions 1, 3, 5 are more flexible, avoid "三平尾" (three consecutive 平 at positions 5-6-7) and "三仄尾" (three consecutive 仄 at positions 5-6-7) — these are considered serious faults even at flexible positions.

## Allowed Tonal Variations (拗救)

In rare cases, a deviation at one position can be "rescued" by an adjustment at another position in the same or adjacent line. However, for this task, prioritize strict compliance over 拗救.
