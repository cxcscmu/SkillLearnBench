name: Build Pinyin-to-Tone Reference Table for Classical Chinese Poetry
description: Create a definitive lookup table mapping each character in your poem to its Mandarin pinyin, tone number (1–4), and 平仄 classification (平=level/rising tones 1–2; 仄=falling/entering tones 3–4). Use only authoritative sources like Xinhua Dictionary. This table serves as your verification anchor before composition and prevents tone misclassification errors.
---

## Process

1. **Select your character set** — List all characters you plan to use in the poem (including rhyme anchors).

2. **Look up each character individually** in Xinhua Dictionary or authoritative digital resource:
   - Record: Character | Pinyin | Tone Number | 平/仄

3. **Double-check rhyme characters especially:**
   - All 4 rhyme characters (lines 2, 4, 6, 8) must have:
     - Same final (e.g., all -ing, all -ang)
     - Matching tone classification (e.g., all 2nd tone)
   - Example valid set: 宁(níng, 2nd, 平), 平(píng, 2nd, 平), 清(qīng, 1st, 平), 声(shēng, 1st, 平)

4. **Format your reference table clearly:**
   ```
   Character | Pinyin | Tone | 平/仄
   宁        | níng   | 2    | 平
   平        | píng   | 2    | 平
   ...
   ```

5. **Post this table visibly** before beginning line composition — use it as a checklist for every single character placement.
