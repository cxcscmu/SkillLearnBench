# Canonical Seven-Character Regulated Verse (七律) Tonal Patterns

## Four Ground-Truth Canonical Forms

### Form 1: Ping-start Ze-end (平起仄收)
Rhyme lines: 2, 4, 6, 8 (end in 平). Line 1 ends in 仄.

```
Line 1: 平平仄仄平平仄   (no rhyme, ends 仄)
Line 2: 仄仄平平仄仄平   (rhyme, ends 平)
Line 3: 仄仄平平平仄仄   (no rhyme, ends 仄)
Line 4: 平平仄仄仄平平   (rhyme, ends 平)
Line 5: 平平仄仄平平仄   (no rhyme, ends 仄)
Line 6: 仄仄平平仄仄平   (rhyme, ends 平)
Line 7: 仄仄平平平仄仄   (no rhyme, ends 仄)
Line 8: 平平仄仄仄平平   (rhyme, ends 平)
```

### Form 2: Ping-start Ping-end (平起平收)

```
Line 2: 仄仄平平仄仄平   (rhyme, ends 平)
Line 3: 仄仄平平平仄仄   (no rhyme, ends 仄)
Line 4: 平平仄仄仄平平   (rhyme, ends 平)
Line 5: 平平仄仄平平仄   (no rhyme, ends 仄)
Line 6: 仄仄平平仄仄平   (rhyme, ends 平)
Line 7: 仄仄平平平仄仄   (no rhyme, ends 仄)
Line 8: 平平仄仄仄平平   (rhyme, ends 平)
```

### Form 4: Ze-start Ping-end (仄起平收)
Rhyme lines: 1, 2, 4, 6, 8 (end in 平).

```
Line 1: 仄仄平平仄仄平   (rhyme, ends 平)
Line 2: 平平仄仄仄平平   (rhyme, ends 平)
Line 3: 平平仄仄平平仄   (no rhyme, ends 仄)
Line 4: 仄仄平平仄仄平   (rhyme, ends 平)
Line 5: 仄仄平平平仄仄   (no rhyme, ends 仄)
Line 6: 平平仄仄仄平平   (rhyme, ends 平)
Line 7: 平平仄仄平平仄   (no rhyme, ends 仄)
Line 8: 仄仄平平仄仄平   (rhyme, ends 平)
```

## Key Verification Rule: Positions 2, 4, 6

For every line, positions 2, 4, 6 must strictly match the pattern (these are the "obligatory" positions). Position 1, 3, 5 have more flexibility ("一三五不论"), but positions 2, 4, 6 are strict ("二四六分明").

## Modern Mandarin Tone Classification

- **平 (level)**: Tones 1 (阴平) and 2 (阳平)
- **仄 (oblique)**: Tones 3 (上声) and 4 (去声)
