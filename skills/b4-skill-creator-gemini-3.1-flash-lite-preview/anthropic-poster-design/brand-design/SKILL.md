# Anthropic Brand Design Standards

## Color Palette
Use these exact hex codes for all brand-consistent artifacts:

| Role | Color Name | Hex Code |
| :--- | :--- | :--- |
| Background | Identity Light | #F5F4F0 |
| Casing | Corporate Dark | #1A1A1A |
| Primary | Primary Brand Accent | #D9534F |
| Secondary | Secondary Brand Accent | #5BC0DE |
| Tertiary | Tertiary Brand Accent | #F0AD4E |
| Lines | Muted Mid Gray | #888888 |

## Typography
- Use clean, sans-serif fonts. Preferred: Helvetica Neue, Arial, or Inter.
- Heading font: "Inter Bold"

## Visual Aesthetic
- **Minimalist:** High white space usage.
- **Low-Saturation:** Avoid vibrant/neon colors.
- **Clean:** Focus on clarity, precision, and utility.
- **Form:** Avoid AI-style gradients; prefer solid colors with subtle drop shadows or light gradients only for depth.
