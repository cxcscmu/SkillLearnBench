# Anthropic Brand System

## Overview

Anthropic's brand identity is characterized by:
- **Minimalist aesthetic** with clean lines and ample whitespace
- **Professional, tech-forward** visual language
- **Muted, low-saturation colors** avoiding neon or intense gradients
- **Consistent typography** across all materials

This skill provides the authoritative color tokens and design standards for branded artifacts.

---

## Color Palette & Brand Tokens

### Primary Colors

| Token Name | Purpose | Hex Value | Notes |
|---|---|---|---|
| Anthropic Corporate Dark | Primary container, casing, dark elements | `#1A1A1A` | Deep charcoal; primary dark anchor |
| Anthropic Identity Light | Background, neutral canvas | `#F8F8F8` | Warm off-white; reduces eye strain |
| Primary Brand Accent | Interactive elements, connectors, highlights | `#0D47A1` | Deep blue; used for critical UI elements |
| Secondary Brand Accent | Thermal/mechanical subsystems | `#1565C0` | Medium blue; complementary to primary |
| Tertiary Brand Accent | PCB, circuitry, digital components | `#42A5F5` | Lighter blue; technical substrates |
| Muted Mid Gray | Annotation lines, guidelines, secondary text | `#9E9E9E` | Medium gray; 60% opacity for leader lines |

### Color Application Strategy

1. **Backgrounds**: Always use **Anthropic Identity Light** as the main poster/canvas background
2. **Primary Containers**: Use **Corporate Dark** for outer casings, bezels, and main structural elements
3. **Mechanical Systems**: Use **Secondary Brand Accent** for thermal management, cooling units, mechanical components
4. **Digital Systems**: Use **Tertiary Brand Accent** for PCBs, circuitry, and logic substrates
5. **Interactive Highlights**: Use **Primary Brand Accent** for connectors, ports, and primary interaction points
6. **Annotation**: Use **Muted Mid Gray** (typically 40-60% opacity) for leader lines, dimension lines, and secondary callouts

### Saturation & Vibrancy Rules

- All colors should be **muted and desaturated** relative to pure RGB values
- Avoid neon, high-intensity, or "AI gradient" styling
- Maintain **professional, enterprise-grade** appearance
- Opacity should be used strategically to create hierarchy without saturation increase

## Typography Standards

### Heading Font

- **Font Family**: Inter (sans-serif)
- **Weight**: 700 Bold
- **Size**: 48-64px for main titles
- **Letter Spacing**: +0.5px for titles
- **Color**: **Corporate Dark** (`#1A1A1A`)

### Body Text & Annotations

- **Font Family**: Inter or system sans-serif fallback
- **Weight**: 400-500 Regular
- **Size**: 12-14px for annotations
- **Color**: **Corporate Dark** at 80-100% opacity or **Muted Mid Gray** for secondary callouts

### Font Application Rules

1. **Product Title (e.g., "NOVA")**: Use Inter 700 Bold, 56px, Corporate Dark, positioned top-left in a clean heading block
2. **Component Labels**: Use Inter 400, 12px, Corporate Dark with 90% opacity
3. **Specification Callouts**: Use Inter 500, 11px, Muted Mid Gray with 80% opacity for leader line annotations

## Design Principles

### Minimalism

- **Low visual density**: Avoid cluttered layouts
- **Generous whitespace**: Let components breathe
- **Focus through contrast**: Not through color intensity
- **Rule of thirds**: Position major elements along compositional thirds

### Technical Illustration Style

1. **Exploded views** should show clear separation between layers with consistent spacing
2. **Annotation leader lines** connect labels to components via thin, subtle lines (Muted Mid Gray, 40-60% opacity)
3. **Avoid drop shadows or 3D effects** unless essential for layer clarity
4. **Use flat geometry** with clean edges; subtle gradients (if any) should be linear and muted

### Brand Coherence

- All colors must be applied from the palette above (no custom hex values outside this list)
- Typography hierarchy uses size and weight, not color variation
- Spacing should follow a 4px or 8px grid system
- Opacity is preferred over color desaturation for visual hierarchy

## Checklist for Branded Materials

- [ ] Background is **Anthropic Identity Light** (#F8F8F8)
- [ ] All colors used are from the approved palette above
- [ ] Typography uses **Inter** family with specified weights and sizes
- [ ] Neon, intense gradients, or "AI styling" is **NOT** present
- [ ] Color saturation is **muted and professional**
- [ ] Annotation leader lines are **Muted Mid Gray** at 40-60% opacity
- [ ] Component hierarchy is clear through positioning and size, not color intensity
- [ ] Ample whitespace is preserved throughout the design
