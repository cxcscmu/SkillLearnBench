# Verification Checklist for 七言律诗

## Format Requirements
- [ ] **Title present**: One line with poem title
- [ ] **Total lines**: Exactly 8 lines
- [ ] **Characters per line**: Exactly 7 characters in each line
- [ ] **No extra spaces or formatting**: Clean, readable text

## Rhyme Scheme (韵脚)
- [ ] **Lines 2, 4, 6, 8 rhyme**: Check ending sounds using modern Mandarin pronunciation
- [ ] **Rhyme consistency**: All 4 rhyming lines use same rhyme category (-ang, -ing, -an, etc.)
- [ ] **Clear rhyme words**: Rhyming characters are identifiable and natural-sounding

## Parallel Couplets (对仗)
- [ ] **Lines 3-4 form couplet**:
  - [ ] Grammatical structure mirrors each other
  - [ ] Word positions correspond (Adj-Adj, Verb-Verb, Noun-Noun)
  - [ ] Semantic relationship: contrast, parallel, or complementary
- [ ] **Lines 5-6 form couplet**: Same checks as 3-4

## Content Requirements
- [ ] **Theme**: Focuses on peace, tranquility, or anti-war sentiment
- [ ] **War suffering**: Clearly describes difficulties, hardship, or devastation
- [ ] **Peace longing**: Expresses hope, prayer, or yearning for peace
- [ ] **Ordinary perspective**: Voice represents common people, not rulers or warriors
- [ ] **Emotional coherence**: Narrative flows from suffering → longing → hope

## Language Quality
- [ ] **Natural diction**: Words and phrases sound poetic, not forced
- [ ] **Meaningful imagery**: Vivid descriptions that evoke emotion
- [ ] **Character appropriateness**: Each character fits context and meaning
- [ ] **No anachronisms**: Language feels classical Chinese, not modern

## Modern Mandarin Compliance
- [ ] **Rhyming based on modern pronunciation**: Not historical Middle Chinese
- [ ] **Readable in modern context**: But maintains classical style
