# Tonal Patterns in Seven-Character Regulated Verse

## Modern Mandarin Tones
- **平 (píng, level)**: Tones 1-2 (high level, rising)
- **仄 (zè, oblique)**: Tones 3-4 (low-rising, falling)

## Standard Tonal Pattern for 七言律诗 (7-character regulated verse)

### Pattern Type A (lines 1, 3, 5, 7):
**平平仄仄平平仄** (level-level-oblique-oblique-level-level-oblique)

### Pattern Type B (lines 2, 4, 6, 8):
**仄仄平平仄仄平** (oblique-oblique-level-level-oblique-oblique-level)

## How to Apply
- Alternate between pattern A (odd lines) and pattern B (even lines)
- The final character of the line should match the pattern
- Key positions to check: position 1, 2, 3, 4, 5, 6, 7

## Example Check
For line: 烽火连年燃四方
- 烽(píng-平) 火(huǒ-仄) 连(lián-平) 年(nián-平) 燃(rán-平) 四(sì-仄) 方(fāng-平)
- Pattern: 平仄平平平仄平
- Should be: 平平仄仄平平仄
- **Mismatch!** Position 2 should be 平 but is 仄

## Practical Approach
When composing, check character tones:
1. Use tone mark guides (common characters with their tones)
2. Verify against the required pattern
3. Adjust characters if tonal pattern doesn't match
