# Brand Standards Skill (V2)

Use this skill for:
- Mapping internal brand tokens to approved HEX codes.
- Managing JSON-based design specifications for interoperability.

## Verified Color Palette
- Background (Identity Light): #F4F3F0
- Corporate Dark: #1A1A1A
- Primary Accent: #0066CC
- Secondary Accent: #5E5E5E
- Tertiary Accent: #A6A6A6
- Muted Mid Gray: #808080

## Design Guidelines
- Minimalist style: Low-saturation colors, no gradients.
- Typography: Use standard sans-serif (e.g., Inter).
- Annotations: Leader lines must be Muted Mid Gray (1px).
