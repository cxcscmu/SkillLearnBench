To output the final file at `\root\poem.txt`:
1. Open the file for writing.
2. Write the title as the very first line of the document.
3. Write exactly eight subsequent lines of text, ensuring no trailing empty lines or additional metadata labels are included.
4. Perform a final count check: verify the file contains exactly nine lines of text (1 title + 8 lines of verse).
