# Anthropic Brand Standards

This skill provides the official HEX color codes and typography guidelines for Anthropic's corporate identity. Use these exact values when generating Anthropic-branded visual artifacts or design parameters.

## Color Palette

Anthropic uses a specific set of muted, earthy tones paired with distinct accents to maintain a clean, low-saturation, and non-neon aesthetic.

### Core Identity
- **Identity Light** (Backgrounds): `#faf9f5`
- **Corporate Dark** (Text, Outer Casing, primary dark elements): `#141413`

### Accents
- **Primary Brand Accent** (Anthropic Orange, used for key interaction details and connector highlights): `#d97757`
- **Secondary Brand Accent** (Blue, used for secondary elements like Thermal Management units): `#6a9bcc`
- **Tertiary Brand Accent** (Green, used for tertiary elements like PCB substrates): `#788c5d`

### Supporting Colors
- **Muted Mid Gray** (Annotation leader lines, borders, secondary text): `#b0aea5`

## Typography

Anthropic's typographic style aims for clarity and a sophisticated, academic feel.

- **Primary Heading Font**: `Reckless Neue` (often used for bold product titles and editorial headings).
- **Secondary/Body Font**: `Inter` or custom `Anthropic Sans` (often resembling `Styrene A` or `Poppins`).

For JSON configurations or applied heading font fields, use `Reckless Neue` or `Anthropic Sans`. 

## Aesthetic Guidelines
- **Low-Saturation**: Always keep the overall image minimalist and low-saturation.
- **No Neon/Gradients**: Explicitly avoid neon colors, "AI gradient" styling, or high-intensity glowing effects.
- **Clean Formatting**: Use generous white/light space. Place titles clearly (e.g., top-left as a heading block).
